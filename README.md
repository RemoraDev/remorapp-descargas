# RemorApp — Descargas

Canal oficial de descarga y actualización de **RemorApp** para Windows.

## Descargar

**[Descargar RemorApp para Windows](https://github.com/RemoraDev/remorapp-descargas/releases/latest/download/RemorApp-Setup.exe)**

También podés verlo desde la propia aplicación web, en la página de Inicio.

### Al instalar

Windows puede mostrar un aviso de SmartScreen la primera vez. Es lo habitual en
instaladores que todavía no acumularon reputación de descargas. Para continuar:
**Más información → Ejecutar de todas formas**.

### Actualizaciones

RemorApp se actualiza sola. Comprueba si hay una versión nueva al abrirse y cada
cuatro horas, y avisa con un botón para instalarla. **No se instala sin
confirmación**: actualizar obliga a reiniciar la aplicación, y eso no debería
pasar sin avisar mientras alguien la está usando, por ejemplo en medio de una
transmisión.

Cada instalador está firmado digitalmente. La aplicación verifica esa firma
antes de aplicar una actualización y rechaza cualquier archivo que no esté
firmado con la clave correcta.

## Qué hay en este repositorio

Solo las descargas: los instaladores, el manifiesto de actualización
(`latest.json`) y este archivo.

**El código fuente de RemorApp no está acá y no es público.**
